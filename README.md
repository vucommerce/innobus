## 🌟 Overview

**INNOBUS 2027** is the official static website for the 28th Annual International Conference of the Department of Commerce, Vidyasagar University. The website has been designed with inspiration from modern academic conference portals, featuring distinct colorful sections, responsive layout (Tailwind CSS), countdown timers, live interactive sub-theme filters, one-click copy for bank transfer info, high-resolution QR payment card, accommodation directory, and photo gallery with modal lightbox.

## 🌐 How to Deploy to GitHub Pages (Free)

This website uses pure **HTML5, CSS3, and modern Vanilla JavaScript** with Tailwind CDN and FontAwesome CDN, making it **100% compatible with GitHub Pages** without requiring any build step, Node.js, or server.

### Steps to Deploy:

1. **Initialize Git Repository (if not already done):**
   ```bash
   git init
   git add .
   git commit -m "Initial commit for INNOBUS 2027 website"
   ```

2. **Create a GitHub Repository:**
   - Go to [GitHub](https://github.com/new) and create a repository named e.g., `innobus2027` (or `vucommerce.github.io`).

3. **Push Files to GitHub:**
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages:**
   - Go to your repository **Settings** &rarr; **Pages** (under Code and automation).
   - Under **Build and deployment** &rarr; **Branch**, select `main` branch and folder `/ (root)`.
   - Click **Save**.
   - Your website will be live in ~1-2 minutes at:  
     `https://<your-username>.github.io/<repo-name>/`
